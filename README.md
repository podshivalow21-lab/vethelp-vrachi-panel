# VetHelp · панель врача (зеркало для VPN)

Публичное зеркало клиники «Ветхэлп» — веб-панель врача (Whisper в браузере).

- Это VPN-friendly mirror: основной URL на Яндексе может не открываться из‑за VPN.
- Пароль панели остаётся временным и проверяется только на клиенте (в браузере).
- Исходники: `index.html`, `styles.css`, `app.js`.

Сайт: https://podshivalow21-lab.github.io/vethelp-vrachi-panel/
