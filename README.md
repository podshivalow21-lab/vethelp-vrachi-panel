# Помощник врача · Ветхэлп (веб-панель)

Узкая страница-помощник рядом с Vet.AF: вход → запись приёма → **бесплатная расшифровка прямо в браузере (Whisper)** → текст → черновик медкарты → копирование полей вручную.

**Рекомендуемый браузер: Яндекс.Браузер.** Платный Яндекс SpeechKit и Cloud Function **не используются**. Win+H и Web Speech Google в РФ часто недоступны — эта панель их не требует.

## Как открыть рядом с Vet.AF

1. Откройте Vet.AF в **Яндекс.Браузере** (слева).
2. Откройте эту панель вторым окном (справа):
   - живой хостинг (ссылка выше), или
   - локальный сервер (см. ниже).
3. Поставьте окна рядом (`Win + ←` / `Win + →` или вручную ~380–420 px).
4. Введите общий пароль врачей на экране входа.
5. Разрешите микрофон, когда браузер спросит.
6. **Первый запуск:** подождите загрузку модели Whisper (~75–80 МБ) — дальше быстрее из кэша браузера. Интернет нужен только чтобы скачать модель один раз.

## Пароль (общий для врачей)

- Временный демо-пароль: `vethelp-vrachi` (Николай потом сменит).
- Константа в коде: `PANEL_PASSWORD` в `app.js` — **смените перед выкладкой**.
- После верного входа флаг в `sessionStorage` вкладки.
- Проверка на клиенте — базовая защита «от случайных глаз», не fort knox.

## Запись голоса (бесплатно, локально)

1. **Старт** → `getUserMedia` + `MediaRecorder` (как раньше).
2. **Стоп** → аудио декодируется в PCM 16 kHz mono на клиенте.
3. Расшифровка **локально в браузере** через [Transformers.js](https://huggingface.co/docs/transformers.js) (`@huggingface/transformers` с CDN) и модель **`Xenova/whisper-base`** (multilingual, лучше русский; WASM `q8`, WebGPU без `q8`).
4. Текст дописывается в «Текст приёма» (`#visit-text`).
5. Статусы: «Загружаю модель…» / «Расшифровываю…» / «Идёт запись…».
6. Без `SPEECH_API_URL`, без ключей, без fetch на Cloud Function / SpeechKit.

### Откуда грузится код и модель

| Что | Откуда |
|-----|--------|
| Библиотека Transformers.js | CDN jsDelivr: `https://cdn.jsdelivr.net/npm/@huggingface/transformers@3.5.1` |
| Модель Whisper base (ONNX) | Hugging Face Hub: `Xenova/whisper-base` (~75–80 МБ), кэш в IndexedDB браузера |
| Ускорение | WebGPU (fp32/q4 encoder/decoder, не q8) если есть, иначе WASM q8 |

Нужны WebAssembly (и желательно современный Chromium / Яндекс.Браузер). Если WASM/WebGPU недоступны — понятная ошибка по-русски.

Страница остаётся **статикой** (Object Storage): ES-modules с CDN, без npm-сборки.

## Что умеет (MVP)

- Вход по общему паролю.
- Запись через MediaRecorder → локальный Whisper.
- Поле «Текст приёма», черновик по маркерам, копирование полей.
- Статусы загрузки модели и расшифровки, ошибки по-русски.

## Локальный превью

```bash
cd /workspace/team/doctors/web-panel
python3 -m http.server 8765
```

Микрофон с `file://` может не работать — лучше HTTP(S). ES-modules тоже требуют HTTP(S), не `file://`.

## Установка как приложение (PWA)

На панели после входа — кнопка **«Установить»** (не путать со **«Старт»** записи). Подсказка: «На рабочий стол / в приложения».

- Chromium / Яндекс.Браузер: `beforeinstallprompt` → кнопка вызывает системный диалог.
- После успешной установки (`appinstalled`, режим `standalone` или флаг в `localStorage`) кнопка **больше не показывается** на этом устройстве/браузере.
- Если браузер не умеет `beforeinstallprompt` (Safari и т.п.): вместо мёртвой кнопки — строка «В меню браузера: Установить приложение / На экран Домой».
- Нужны HTTPS (бакет / GitHub Pages) или localhost, `manifest.webmanifest` и `sw.js`.

## Файлы

- `index.html` — разметка (`script type="module"`), манифест, блок «Установить»
- `styles.css` — узкая светлая тема
- `app.js` — пароль, MediaRecorder, клиентский Whisper, черновик, буфер обмена, PWA-установка
  - `PANEL_PASSWORD` — не менять без согласования
  - модель: `Xenova/whisper-base`
- `manifest.webmanifest` — имя, иконки, `display: standalone`
- `sw.js` — минимальный service worker (условие installability в Chromium)
- `icon-192.png`, `icon-512.png`, `icon-512-maskable.png` — иконки приложения
